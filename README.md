# 📍 GeoCalculator

**Android-based location tracking and geo-coordinate conversion app for students and parents**

BS (Hons.) Information Technology, Final Year Project
[University of Gujrat](https://uog.edu.pk), Pakistan


---

## 📖 Overview
GeoCalculator was an Android-based web application designed for students and their parents. It tracked the user's location and updated it on a server, so parents could monitor their children's location. It also provided geocoding and geolocation tools, including conversion between longitude and latitude formats, and worked both online and offline.

## ✨ Key Features
- 📍 Tracked the user's location and updated it on a server
- 👨‍👩‍👧 Let parents monitor their children's location
- 🌐 Geocoding and geolocation support
- 🔄 Conversion between longitude and latitude formats
- 📴 Worked both online and offline

## 🌍 Applications of Geographic Coordinates
- **Navigation:** guiding ships, planes and vehicles via GPS
- **Mapping:** pinpointing addresses and geographic features on globes and digital maps
- **Time zones and climate patterns:** locating regions for time and weather analysis

## 🛠️ Technologies Used
- Android
- HTML, CSS, JavaScript
- PHP and MySQL
- Google Maps API
